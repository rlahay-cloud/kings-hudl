Kings Highlight Video

Makes one highlight video for a game from the clips you pick, in game order. Goals and anything in a Highlight playlist start ticked; you can tick any other mark from Kings Film Room too (a single save, a back check, a playlist). Each clip has a Kings graphic on each showing the player's number and name (goals also show the assists). The clip list comes from Kings Film Room.
The video is cut on this computer from your full game video. Nothing is uploaded.

First time only
1. Double click Install_Kings_Highlights.bat and wait for DONE (about 2 minutes).
2. A "Kings Highlight Video" shortcut appears on the desktop.

Every game
1. Double click Kings Highlight Video.
2. Choose the full game video.
3. Pick the game date. If the game has extra cameras, choose each camera's video file (skip any you don't have). Each goal then gets one short replay from the camera behind the net the Kings scored on, marked REPLAY (tick the Replay column to add one to any other clip). Say which camera is at the end the Kings attack in period 1; the program swaps it each period.
4. Press "Test the first clip" and watch it. If it starts at the wrong moment, change "Seconds to add"
   (a minus number like -12 if the clips start too late, a plus number if they start too early) and test again.
5. Press "Make the highlight video". It opens when done.
Videos are saved in Documents\KingsHighlights.

Files for the Download buttons
Press "Make a file for every clip (for downloads)". Each goal, save and highlight gets its own small video
in Documents\KingsHighlights\clips_DATE, with a clips.json list. Running it again skips clips already cut.

Vertical version: tick "Also make a tall version" for a phone-shaped copy saved next to the main video (name ends in _vertical). Say which side of the picture the Kings attack in period 1, then use "Check the framing..." to slide the box over the action for any clip that is off.
Cutting uses the graphics card automatically when it can, and the processor otherwise.

Power play and short handed goals
If a goal was scored while a penalty was running (from the penalties you marked in the Film Room), the picture caption says POWER PLAY GOAL or SHORT HANDED GOAL, and the pick list shows PP or SH after the goal.
