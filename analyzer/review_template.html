Kings HUDL analyzer review

1. Which colours are your team?

Tap every group that shows the Kings (more than one if your team was split, for example by a dark helmet or a goalie). Tap again to undo. The program only guesses colours, so a referee or goalie may land in a group by mistake. You can fix any single box below.

2. Name each box

Type the jersey number for each Kings box. If you cannot read it, tap the picture to make it bigger, or leave it empty. Use x for a box that is not a skater. The same number on several boxes means that player came on the ice several times.

3. Shifts for the Shifts tab

Stoppages are a guess from nobody moving. Look them over on the site before you save.

Ice time so far

4. Goals, penalties and stoppages from the scoreboard

Game clock:

Each goal is saved 12 seconds before the scoreboard changed, because the person running the board taps a little after the goal. On the site, open Coach's Corner, then Game analysis, pick the game, open Add goals and penalties from the game analyzer (near the bottom), and paste these lines. Check each one by watching it.

5. Faceoffs with zone

Found from the scoreboard clock starting again. Tap Win, Loss or Skip. The spot on the ice and the zone are worked out from the blue lines. Say which way the Kings attack in each period, since that decides which end is the offensive zone.

Faceoff win percent by zone

Paste into Kings HUDL, Game analysis, "Add goals and penalties from the game analyzer" box.

6. Line changes and time on ice

Each card is a moment when Kings skaters showed up at or left the bench. Type the jersey numbers that came off and the numbers that came on, separated by commas. The "now on the ice" line is carried forward so you only fix what changed.
