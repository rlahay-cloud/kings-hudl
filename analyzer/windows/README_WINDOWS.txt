Kings HUDL Game Analyzer for Windows

First time only
1. Unzip this folder somewhere you will keep it, for example Documents.
2. Double click Install_Kings_Analyzer.bat and wait until it says DONE (10 to 25 minutes, needs internet).
3. A "Kings Analyzer" shortcut appears on your desktop.

Every game
1. Double click Kings Analyzer on the desktop.
2. Choose the game video. It stays on your computer.
3. Pick "Test: the first 5 minutes" and press Start. Watch the minutes left it shows. Multiply by the game length
   to see how long a full game will take.
4. For the whole game, pick "The whole game", press Start and leave the laptop plugged in. It keeps the
   computer awake. A full game can take a few hours, so overnight is fine.
5. When it finishes, the review page opens in your browser. Choose the same video there when it asks.
6. Copy the lines from the review page into Kings HUDL.

If it stops or you close it: press Start again with "Start over" unticked and it carries on.
Results are saved in Documents\KingsAnalyzer.

If something goes wrong, copy the text from the bottom box of the window and send it to Claude.
